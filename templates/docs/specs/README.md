Each spec states what one area of the product does **now**, in the present tense. A requirement has
a stable ID (`AUTH-3`) that tests cite in their names, so the tests read as proof of the spec.

Specs change in the same commit as the behavior they describe. Proposed behavior lives in
`docs/changes/` until it ships. History lives in git and `docs/adr/`.
